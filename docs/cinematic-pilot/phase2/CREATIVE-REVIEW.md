# Cidea Marketing – Kreativ vurdering av Stitch-runde 1

**Dato:** 2026-10-15
**Grunnlag:** Visuell gjennomgang av `oversikt-runde1.png` (desktop- og mobilutsnitt av A, B, C), kombinert med beskrivelser og avvik i `README.md`. Den komplette langversjonen av alle tre er ikke visuelt ferdigvurdert i denne gjennomgangen; dette er en foreløpig art-direction-vurdering, ikke endelig godkjenning av hele sidene.
**Status:** Fase 2 fortsetter inntil bruker velger en retning eller bestiller målrettet iterasjon.

## A – Skulpturell redaksjon

**Styrker:** Faglig tillitvekkende premium-/editorial-typografi, mye luft, enkel CTA, strukturert mobiloppsett, en stil som også kan tilpasses konsulent- og serviceinnhold.

**Svakheter:** Svært mange andre luksus-/studio-nettsteder benytter tilsvarende serif, off-white og skulpturfotografi. Avhengig av AI-genererte steinbilder med rettigheter som må verifiseres. Stor hero-tekst kan bli ordrik og en lite konkret beskrivelse av markedsføringstjenestene. Noen udokumenterte påstander i tekst.

**Før godkjenning:** Kortere hero, mer karakteristisk konseptgrafikk eller reelle egne foto, tydelig salgstilbud, kontroller all bildelisens.

## B – Digital avantgarde

**Styrker:** Sterkt visuelt kontrastnivå, tydelig teknologiposisjonering, gjenkjennelig syregrønn signalfarge, god CTA-synlighet.

**Svakheter:** Mørk, neonpreget «AI-/tech agency»-stil er ikke automatisk mer original. Desktop er mer uttrykksfull enn mobil; mobil har en betydelig enklere, lettere typografi. Små mono-etiketter og abstrakt glassgrafikk må ikke ta over for faktisk verdiforslag. AI-grafikkens rettigheter må avklares. Unngå falske steder, oppdiktede lab-/kompetansepåstander.

**Før godkjenning:** Tydeligere konsistent mobiltypografi, sterkere egenart i grafikk og mindre instrumentpanel-/systemspråk.

## C – Fremtidig håndverk (v2)

**Styrker:** Distinkt modulært grafisk språk, illustrasjoner som kan realiseres/tilpasses i SVG og CSS med null nye mediekostnader, fleksibel farge- og komponentsystematikk. Lett å utvide til tjenester, blogg og kundeprosjekter. God tydelig CTA på desktop/mobil.

**Svakheter:** Kan virke for lekent eller ferdigmal-aktig dersom store knapper, rammer og illustrerte kort ikke løftes til et mer bevisst premium-nivå. Serif-aksent på ett enkelt hero-ord kan gi inkonsistent typografisk hierarki. Hero-teksten i B/C er nesten lik; nettopp C bør ha særskilt språk. «Bespoke formgivning», «100 % fotofri profil» og «Eksperiment A/B/C» trenger omskriving/fjerning. Mobil illustrasjon og marger krever nærmere QA.

**Før godkjenning:** Én helhetlig typografisk idé, færre dekorative kanter, mer originale signaturillustrasjoner, bedre mobilkomposisjon og tydeligere norsk verdiforslag.

## Foreløpig kreativ anbefaling

**Anbefal konsept C som utgangspunkt for én fokusert forbedringsrunde**, ikke som ferdig design. Dette valget begrunnes i et mer overførbart og kommersielt rettighetsvennlig grafisk system som ikke krever betalt AI-video eller usikre fotolisenser. Kombiner ikke tilfeldig deler fra de andre konseptene; bevar C som eget visuelt system. Oppgrader kvaliteten med presise illustrasjoner, typography, layout-rytme og redaksjonell ro.

**Ikke start fase 3 eller kode:** Masterplanen krever at bruker eksplisitt velger konseptet først.

## Fokusert forbedringsbrief for C hvis godkjent
1. Løft uttrykket fra «lekent grafisk nettsted» til visuelt kompromissløs designstudio-standard; lag færre, bedre grafiske objekter.
2. Gjør norsk overskrift konkret og ikke identisk med B; forklar Cidea Marketing-tilbudet innen 5–10 sekunder.
3. Fjern uklar engelsk mikrocopy, uverifiserbare «fotofri»-påstander og «Eksperiment A/B/C».
4. Reduser små rammer og dekorative etiketter som minner om maler; behold sterk modularitet og fargebruk.
5. Design full desktop og mobil hero + ett gjennomført seksjonspar, vis før/etter med screenshots. Ikke generer nytt konsept før bruker godkjenner målrettet revisjon.
6. Registrer faktisk Stitch-forbruk: 34/400 etter A+B+C, 366 tilgjengelig ved brukerens siste avlesning.
7. Verifiser produksjonsrettigheter for alle visualer før lansering.

**Ingen implementasjon, deploy eller betalingsbeslutning er autorisert.**
