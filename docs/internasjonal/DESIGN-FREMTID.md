# Fremtidig designretning – kun dokumentasjon (ikke implementert)

Vedtatt som **eget, senere designprosjekt**. Ingenting av dette er gjennomført i Dubai-satsingen. Dagens designsystem,
typografi, komponenter, layout og animasjoner er beholdt uendret. Nye sider bruker bare eksisterende klasser og tokens.

Retning (fra oppdraget 28.10.2026):
- Norsk natur som **subtil** inspirasjon – ikke bokstavelige landskapsbilder.
- Lysere og luftigere uttrykk enn dagens mørke profil.
- Premium, modent og moderne. Kunstnerisk og originalt.
- Ingen overdreven naturromantikk, ingen mørk og dyster naturprofil, ikke barnslig eller lekent.
- Fargepalett er **ikke** bestemt.

Hensyn når prosjektet starter:
- Lysere bakgrunn krever ny kontrollert kontrast for blå knappetekst og dempet brødtekst (dagens verdier er målt mot mørk bakgrunn).
- 3D-scenen på forsiden er laget for mørk bakgrunn (`mix-blend-mode: screen`) og må vurderes på nytt.
- Engelsk og norsk deler komponenter, så endringer slår ut på begge språk samtidig. Det er en fordel.
- Sosiale medier følger dagens profil (INNHOLDSSTRATEGI.md § 7) til ny profil er godkjent.
