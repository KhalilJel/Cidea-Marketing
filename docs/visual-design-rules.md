# Cidea visual design rules

These rules apply to future visual refinements across Cidea's owned websites unless a specific design concept gives a clear reason to do otherwise.

- **No decorative numbering:** Do not add labels such as “01”, “02”, or “03” just to make cards or sections look designed. Use numbering only when sequence or hierarchy genuinely matters.
- **No duplicate labels:** A small eyebrow or category label must add context; it must not repeat the heading below it.
- **Every element needs a job:** Remove decorative copy and UI that does not improve meaning, hierarchy, navigation, or the overall composition.
- **Review the whole visual:** Evaluate typography, spacing, alignment, balance, contrast, rhythm, and repetition—not just code correctness.
- **Keep design intentional:** Asymmetry and decoration should feel deliberate, not like accidental results of a grid or template.
- **Preserve the brand system:** Refine within the existing visual direction unless a broader redesign is explicitly requested.
