# Launch checklist

## Technical
- [ ] Connect domain to hosting
- [ ] Verify HTTPS
- [ ] Confirm sitemap.xml is reachable
- [ ] Confirm robots.txt is reachable
- [ ] Verify canonical URLs
- [ ] Verify mobile layout
- [ ] Run production build

## SEO
- [ ] Add property in Google Search Console
- [ ] Submit /sitemap.xml
- [ ] Request indexing for homepage and priority service pages
- [ ] Check indexing after launch

## Conversion
- [ ] Test all mailto CTAs
- [ ] Confirm contact email receives messages
- [ ] Test Norwegian and English navigation

Do not change DNS/MX as part of this checklist unless explicitly required for website hosting.
