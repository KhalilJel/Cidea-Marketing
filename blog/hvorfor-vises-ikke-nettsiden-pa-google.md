# Hvorfor vises ikke nettsiden på Google?

Det kan være mange grunner til at en nettside får lite synlighet i Google. Teknisk struktur, innhold, søkeintensjon, konkurranse og autoritet spiller alle en rolle.

## Start med det grunnleggende

Google må kunne finne og forstå sidene dine. Deretter må innholdet svare godt på det folk faktisk søker etter.

Det er derfor SEO ikke bare handler om å legge inn søkeord. Det handler om å bygge en nettside som både søkemotorer og mennesker forstår.

## Se på kommersiell relevans

Det er bedre å rangere på søk fra personer som faktisk kan bli kunder enn å få trafikk fra irrelevante søk.
